# Peshawari Dairy Ice Cream - Frontend

Next.js frontend application for Peshawari Dairy Ice Cream.

## Getting Started

1. Copy environment variables:
   ```bash
   cp .env.example .env.local
   ```
2. Set `NEXT_PUBLIC_BACKEND_URL` to point to your backend API URL (e.g., `http://localhost:4000`).
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
npm start
```
